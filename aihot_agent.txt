最新 50 条精选，保留摘要、站内阅读和原文入口；体积更小，推荐大多数阅读器使用。
https://aihot.virxact.com/feed.xml
精选全文 按需
同样保留 50 条；仅对明确允许再分发的来源内联正文，体积更大，需要阅读器内全文时选用。
https://aihot.virxact.com/feed/full.xml
最近 7 天公开池
最新 50 条公开动态，不含公众号、未审内容和 arXiv 论文。适合自己筛选。
https://aihot.virxact.com/feed/all.xml
AI HOT 日报
每天北京时间 08:00 发布一条精编日报，保留最近 30 期。
https://aihot.virxact.com/feed/daily.xml
给 RSS reader / Agent 的合同 支持 ETag 与 Last-Modified；未变化时返回 304。建议每 30 分钟或更慢轮询。
条目 link 指向 AI HOT 站内阅读页，第三方原文在 description 中。
默认精选与分类 feed 提供摘要，不输出 content:encoded。
全文 feed 仅在来源明确允许时提供 content:encoded 正文。
公众号、付费墙及默认网页/RSS 来源只提供摘要，不外发全文。
分类订阅： /feed/category/ {ai-models|ai-products|industry|paper|tip} .xml
分类全文： /feed/full/category/ {ai-models|ai-products|industry|paper|tip} .xml
RSS 是公开阅读面，不代表第三方内容获得新的许可。镜像或对外发布时请保留 AI HOT 署名和原文入口。
REST API · 程序与自定义 Agent
一个请求开始，严格合同看 OpenAPI
v 1.5.0
无需 token，只允许匿名 GET。要长期维护全部精选，用一次快照加增量游标； 临时查询最近内容继续用 items。字段、错误码和 schema 以 OpenAPI 3.1 为准。
打开 OpenAPI YAML 查看当前版本
首次请求
UA="your-app/1.0 (+mailto:you@example.com)"
curl -H "User-Agent: $UA" 'https://aihot.virxact.com/api/public/items?mode=selected&take=20' 复制 长内容可左右滑动
请把 your-app/1.0 和联系方式替换成你自己的标识；不要在生产中原样使用示例 UA，也不要伪装浏览器。
看到 blocked / 567 ？这不等于 IP 被封 这表示请求先被边缘安全规则拦截。旧 Agent 请先更新 Skill；自建程序请移除 Mozilla、Chrome、HeadlessChrome 等浏览器 UA，改用上面的可识别非浏览器 UA 后只重试一次。仍失败时，请在反馈中附上 requestId 。
默认精选 不传 mode 等同 selected；只有明确需要公开池时用 all。
完整精选不限 7 天 snapshot 首次拿全，changes 后续只取变化；items 仍是最近 7 天查询。
公开池不等于全库 不含公众号、未审内容、低相关和已合并重复条目。
保留 attribution 默认完整响应包含 AI HOT 来源和 canonical；minimal 不含该字段。
端点速览
GET /api/public/selected/snapshot 当前全部精选；首次完整同步
GET /api/public/selected/changes 精选新增、修改和撤选；后续只取变化
GET /api/public/items 精选或最近 7 天公开池；支持分类、时间和关键词
GET /api/public/hot-topics 当前热点，按多源热度排序
GET /api/public/daily 最新日报
GET /api/public/daily/{date} 指定日期日报
GET /api/public/dailies 日报日期索引
GET /api/public/fingerprint 低流量轮询指纹
GET /api/public/version API 与 Skill 版本
items 查询参数 参数 默认 用途与边界
mode selected selected | all
since now - 7d ISO 8601；早于 7 天会截断
take 50 整数 1–100
category 无 ai-models / ai-products / industry / paper / tip
q 无 关键词，2–200 字
cursor 无 原样回传 nextCursor，不要解析
fields default minimal 仅保留索引和深链字段
表格可左右滑动查看
维护当前全部精选：一次快照，之后只拉变化 # 首次：拿到当前全部精选，并保存响应里的 cursor
curl -H "User-Agent: $UA" 'https://aihot.virxact.com/api/public/selected/snapshot'
# 以后：原样回传 cursor，只拿新增、修改和撤选
curl -H "User-Agent: $UA" 'https://aihot.virxact.com/api/public/selected/changes?cursor=<上次响应的 cursor>' 复制 长内容可左右滑动
每页成功应用后再保存新 cursor 。变化包含新增、标题／摘要等 原地修改和撤选；若返回 409 snapshot_required ，重新取一次快照即可，接口不会静默漏数。
只关心最近头部：先 fingerprint，再拉 items # 每分钟先查轻量指纹；只有变化时才拉 items
curl -H "User-Agent: $UA" 'https://aihot.virxact.com/api/public/fingerprint'
# 只做通知或索引时使用轻量字段
curl -H "User-Agent: $UA" 'https://aihot.virxact.com/api/public/items?mode=selected&take=50&fields=minimal' 复制 长内容可左右滑动
fingerprint 只判断头部条目是否变化；标题、摘要或分类的原地编辑由 items 的 ETag / If-None-Match 感知。
错误与恢复 400 ：参数不合法；按 OpenAPI 修正，不要自动改成宽查询。
409 / snapshot_required ：增量游标无法继续安全续传；重新获取一次完整精选快照。
403 ：检查是否使用了可识别的非浏览器 User-Agent。
567 / blocked ：边缘安全规则在请求到达 AI HOT 前拦截；不等于 IP 被封。移除 Mozilla、Chrome、HeadlessChrome 等浏览器 UA，旧 Skill 先更新，再只重试一次；仍失败请提交 requestId 。
429 ：退避 30–60 秒；不要增加并发重试。
5xx / 超时 ：指数退避，并使用上次成功缓存；测试版不提供 SLA。
使用边界
公开可读，不等于可以忽略来源
重要事实回原文核对 摘要和翻译由 AI 生成。引用数字、政策或原话前，请使用 API 返回的原文 URL 复核。
保留来源和 canonical 对外发布 API 结果时请保留返回的 attribution/canonical；第三方原文版权归原作者。
按频率合同调用 正常会话、RSS 阅读器和分钟级轮询均可使用；收到 429 后退避，不要并发抓取。
测试版，不提供 SLA 兼容性变化和版本更新会写入 changelog；生产关键链路请自行设置缓存、重试和降级。
